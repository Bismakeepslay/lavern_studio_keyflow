    Format layer Keyflow

    Hasil diekspor sebagai layer vektor (pen tool) yang titik dan handle kurvanya bisa diedit. Opsional: pilih file .kf buatan Keyflow berisi layer pen tool, maka seluruh struktur project dan manifest-nya disalin persis dari file itu.

    Format layer vektor (VECTOR) bawaan aktif. Memilih file .kf pen tool buatan Anda di sini adalah cara paling aman.

    Cara import ke Keyflow
    1. Unduh file .kf. Jika diblokir, pakai Unduh ZIP lalu ganti nama .zip menjadi .kf.
    2. Pindahkan ke HP, lalu di Keyflow pilih menu Import project dan buka file itu.
    3. Jika posisi atau ukuran bergeser, ubah Skala koordinat lalu unduh ulang.
